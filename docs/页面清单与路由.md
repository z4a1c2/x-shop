# 电商微信小程序 · 页面清单与路由

## 1. 底部导航（TabBar，4 个）

| 页面 | 路径 | 说明 |
|------|------|------|
| 首页 | pages/home/index | 首页（轮播、金刚区、推荐商品） |
| 分类 | pages/category/index | 分类（三级分类 + 商品） |
| 购物车 | pages/cart/index | 购物车 |
| 我的 | pages/user/index | 个人中心 |

## 2. 非 Tab 页面

| 页面 | 路径 | 说明 | 入参 |
|------|------|------|------|
| 搜索 | pages/search/index | 关键词搜索、热搜/历史 | - |
| 商品列表 | pages/product-list/index | 分类/搜索结果列表 | `categoryId` 或 `keyword` |
| 商品详情 | pages/product-detail/index | 商品详情 + SKU + 加购/购买 | `id`(SPU) |
| 确认订单 | pages/order-confirm/index | 下单页（地址/商品/优惠/运费） | `skuId`,`quantity`,`type`(buy/cart) |
| 支付结果 | pages/pay-result/index | 支付成功/失败结果页 | `orderId` |
| 订单列表 | pages/order-list/index | 订单列表（按状态 Tab） | `status?` |
| 订单详情 | pages/order-detail/index | 订单详情、物流、售后入口 | `id` |
| 收货地址列表 | pages/address-list/index | 地址管理 | `select?` |
| 收货地址编辑 | pages/address-edit/index | 新增/编辑地址 | `id?` |
| 优惠券列表 | pages/coupon-list/index | 我的优惠券/领券中心 | `tab` |
| 会员中心 | pages/member/index | 会员等级、成长值、积分 | - |
| 积分明细 | pages/points-log/index | 积分流水 | - |
| 退款申请 | pages/refund-apply/index | 申请退款/退货 | `orderId` |
| 登录 | pages/login/index | 微信授权登录 | `redirect?` |

## 3. 页面跳转关系

```
首页 ──→ 搜索 ──→ 商品列表 ──→ 商品详情
分类 ──→ 商品列表 ──→ 商品详情
商品详情 ──→ 购物车 / 确认订单
购物车 ──→ 确认订单
确认订单 ──→ 支付结果 ──→ 订单详情
我的 ──→ 订单列表 ──→ 订单详情 ──→ 退款申请
我的 ──→ 会员中心 ──→ 积分明细
我的 ──→ 优惠券列表
确认订单/订单详情 ──→ 收货地址列表 ──→ 收货地址编辑
```

## 4. 登录鉴权策略

- 浏览类页面（首页/分类/商品/搜索）无需登录。
- 下单、购物车、订单、优惠券、会员等页面需登录；未登录时 `redirect` 到登录页，登录后回跳。
- 登录态由云函数 `login` 换取 openid + 自定义 token，前端持久化。

## 5. 页面与云函数对应关系

| 页面 | 主要调用云函数 |
|------|----------------|
| 首页 | `product`(list)、`coupon`(list) |
| 分类 | `product`(list by category) |
| 商品详情 | `product`(detail) |
| 搜索 | `product`(list by keyword) |
| 购物车 | `cart`(list/add/update/remove) |
| 确认订单 | `address`(list)、`coupon`(可用)、`order`(create) |
| 支付结果 | `pay`(发起支付后跳转) |
| 订单列表/详情 | `order`(list/detail/cancel) |
| 优惠券 | `coupon`(list/receive) |
| 会员/积分 | `user`(info/points) |
| 退款 | `order`(refund 相关) |
