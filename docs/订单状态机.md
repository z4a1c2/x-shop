# 电商微信小程序 · 订单状态机

## 1. 订单状态（order.status）

| 状态码 | 状态名 | 说明 |
|--------|--------|------|
| 10 | 待付款 | 已创建，等待支付 |
| 20 | 待发货 | 已付款，等待发货 |
| 30 | 待收货 | 已发货，等待确认收货 |
| 40 | 已完成 | 已确认收货，交易完成 |
| 50 | 已取消 | 用户主动取消 |
| 60 | 已关闭 | 超时未支付，自动关闭 |

## 2. 状态流转

```
        ┌──────────┐  用户取消   ┌──────────┐
        │  待付款  │ ──────────→ │  已取消  │
        │   (10)   │             │   (50)   │
        └────┬─────┘             └──────────┘
             │
             │ 超时未支付(定时触发器)
             ↓
        ┌──────────┐
        │  已关闭  │
        │   (60)   │
        └──────────┘

        ┌──────────┐  支付成功(回调)  ┌──────────┐
        │  待付款  │ ────────────────→ │  待发货  │
        │   (10)   │                   │   (20)   │
        └──────────┘                   └────┬─────┘
                                            │ 商家发货
                                            ↓
                                      ┌──────────┐  确认收货  ┌──────────┐
                                      │  待收货  │ ─────────→ │  已完成  │
                                      │   (30)   │            │   (40)   │
                                      └──────────┘            └──────────┘
```

## 3. 合法流转与触发条件

| 当前状态 | 目标状态 | 触发条件 | 触发方 |
|----------|----------|----------|--------|
| 10 待付款 | 50 已取消 | 用户主动取消 | 用户 |
| 10 待付款 | 60 已关闭 | 超过 `expire_at` 未支付 | 定时触发器 |
| 10 待付款 | 20 待发货 | 微信支付回调验签成功 | 支付回调 |
| 20 待发货 | 30 待收货 | 商家录入物流单号并发货 | 商家后台 |
| 30 待收货 | 40 已完成 | 用户确认收货 / 超时自动确认 | 用户/定时触发器 |
| 任意 | 退款相关 | 见退款状态机（不影响主状态前） | 见下 |

> 仅允许上述单向流转，禁止回退；所有变更需校验前置状态，防止重复操作。

## 4. 关键规则

- **超时关单**：创建订单时写入 `expire_at = created_at + 30min`。定时触发器每分钟扫描 `status=10 且 expire_at < now` 的订单，置为 60 已关闭并**回补库存**。
- **支付幂等**：支付回调按 `out_trade_no` 去重，只有 `status=10` 时才允许流转到 20，避免重复通知导致二次发货。
- **自动确认收货**：发货后 `deliver_at + 7天` 若用户未操作，定时触发器自动置为 40 已完成。
- **取消回补**：50 已取消、60 已关闭均需回补该订单占用/预扣的库存与优惠券、积分。

## 5. 退款状态机（refund.status）

| 状态码 | 状态名 | 说明 |
|--------|--------|------|
| 10 | 待处理 | 已提交，待商家审核 |
| 20 | 待退货 | 商家同意，退货退款中等待买家寄回 |
| 30 | 待收货 | 买家已寄回，等待商家收货验货 |
| 40 | 退款成功 | 退款完成 |
| 50 | 已拒绝 | 商家拒绝退款 |

## 6. 退款流转

```
仅退款(20 待发货前)：
  待处理(10) → 退款成功(40)
  待处理(10) → 已拒绝(50)

退货退款(30 待收货/40 已完成后)：
  待处理(10) → 待退货(20) → 待收货(30) → 退款成功(40)
  待处理(10) → 已拒绝(50)
```

> 退款成功后，退款单金额原路退回，并回补/核销库存、积分（退还），用户券按策略退回或作废。

## 7. 状态与用户可见文案映射

| 状态码 | 前端展示 |
|--------|----------|

| 20 | 待发货 |
| 30 | 待收货（查看物流/确认收货） |
| 40 | 已完成（可评价/申请售后） |
| 50 | 已取消 |
