# 电商微信小程序 · 数据模型设计（云数据库）

## 0. 约定

- 后端为微信云开发，每个实体对应一个**集合（collection）**。
- 通用字段：`_id`（自动生成）、`_openid`（用户相关集合由云函数注入）、`created_at`/`updated_at`（Unix 毫秒时间戳，number）。
- 字段命名采用 `snake_case`（与云数据库内置 `_id`/`_openid` 一致）；前端 DTO 用驼峰，在 `services/` 层映射。
- 金额字段统一用**分（整数）**存储，避免浮点误差。
- 关联关系：外键用字符串引用 `_id`；订单内嵌明细快照，避免商品变更影响历史订单。

## 1. 用户与会员

### user（用户）
| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| openid | string | 是 | 微信 openid，唯一索引 |
| nickname | string | 否 | 昵称 |
| avatar | string | 否 | 头像 fileID |
| phone | string | 否 | 手机号 |
| gender | number | 否 | 0未知 1男 2女 |
| level_id | string | 否 | 会员等级 _id |
| growth | number | 是 | 成长值，默认 0 |
| points | number | 是 | 积分余额，默认 0 |
| status | number | 是 | 1正常 0禁用 |
| last_login_at | number | 否 | 最近登录时间 |

索引：`openid`（唯一）

### member_level（会员等级）
| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| name | string | 是 | 等级名，如「普通/银卡/金卡」 |
| level | number | 是 | 等级序号，越大越高 |
| min_growth | number | 是 | 达成所需最低成长值 |
| discount | number | 是 | 折扣，如 0.95 表示 95 折 |
| points_rate | number | 是 | 积分倍率，如 1.5 |
| status | number | 是 | 1启用 0停用 |

索引：`level`（唯一）

## 2. 商品域

### category（分类）
| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| name | string | 是 | 分类名 |
| parent_id | string | 是 | 父分类 _id，顶级为 `0` |
| level | number | 是 | 1/2/3 |
| icon | string | 否 | 图标 fileID |
| sort | number | 是 | 排序，越小越前 |
| status | number | 是 | 1显示 0隐藏 |

索引：`parent_id`、`level`

### product（商品 SPU）
| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| category_id | string | 是 | 分类 _id |
| name | string | 是 | 商品名 |
| subtitle | string | 否 | 副标题/卖点 |
| cover | string | 是 | 主图 fileID |
| images | array<string> | 是 | 轮播图 fileID 列表 |
| detail | string | 否 | 富文本详情（HTML） |
| price_min | number | 是 | 最低价（分） |
| price_max | number | 是 | 最高价（分） |
| sales | number | 是 | 累计销量，默认 0 |
| status | number | 是 | 1上架 0下架 |
| sort | number | 是 | 排序 |

索引：`category_id`、`status`、`sales`（降序）、`price_min`

### product_sku（SKU 规格 + 库存）
| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| product_id | string | 是 | 所属 SPU _id |
| specs | object | 是 | 规格键值，如 `{颜色:"红",尺码:"L"}` |
| price | number | 是 | 售价（分） |
| original_price | number | 否 | 划线价（分） |
| stock | number | 是 | 库存 |
| sales | number | 是 | 销量 |
| image | string | 否 | 规格图 fileID |
| status | number | 是 | 1有效 0失效 |

索引：`product_id`

## 3. 交易域

### cart（购物车）
| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| product_id | string | 是 | SPU _id |
| sku_id | string | 是 | SKU _id |
| quantity | number | 是 | 数量 |
| checked | boolean | 是 | 是否勾选结算，默认 true |

索引：`_openid`、`sku_id`

### order（订单）
| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| order_no | string | 是 | 订单号，唯一索引 |
| status | number | 是 | 见订单状态机 |
| items | array<object> | 是 | 内嵌明细快照 |
| total_amount | number | 是 | 商品总额（分） |
| freight | number | 是 | 运费（分） |
| discount_amount | number | 是 | 优惠金额（分） |
| pay_amount | number | 是 | 实付金额（分） |
| coupon_id | string | 否 | 使用的用户券 _id |
| points_used | number | 是 | 抵扣积分数 |
| address | object | 是 | 收货地址快照 |
| remark | string | 否 | 买家留言 |
| expire_at | number | 是 | 待付款超时关单时间戳 |
| pay_at | number | 否 | 支付时间 |
| deliver_at | number | 否 | 发货时间 |
| finish_at | number | 否 | 完成时间 |
| cancel_at | number | 否 | 取消时间 |

索引：`order_no`（唯一）、`_openid`、`status`、`expire_at`

> `items` 内嵌对象：`{ product_id, sku_id, name, spec_text, image, price, quantity }`

### payment（支付流水）
| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| order_id | string | 是 | 订单 _id |
| order_no | string | 是 | 订单号 |
| out_trade_no | string | 是 | 商户订单号，唯一 |
| transaction_id | string | 否 | 微信支付单号 |
| amount | number | 是 | 支付金额（分） |
| status | number | 是 | 0待支付 1已支付 2已退款 |
| pay_time | number | 否 | 支付完成时间 |

索引：`out_trade_no`（唯一）、`order_id`

### shipment（物流）
| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| order_id | string | 是 | 订单 _id |
| logistics_company | string | 是 | 物流公司 |
| logistics_no | string | 是 | 运单号 |
| traces | array<object> | 否 | 物流轨迹 |
| deliver_at | number | 是 | 发货时间 |

索引：`order_id`

### refund（退款/售后）
| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| order_id | string | 是 | 订单 _id |
| refund_no | string | 是 | 退款单号，唯一 |
| type | number | 是 | 1仅退款 2退货退款 |
| reason | string | 是 | 退款原因 |
| amount | number | 是 | 退款金额（分） |
| status | number | 是 | 见订单状态机 |

## 4. 营销域

### coupon（优惠券模板）
| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| name | string | 是 | 券名 |
| type | number | 是 | 1满减 2折扣 |
| threshold | number | 是 | 使用门槛金额（分），0 表示无门槛 |
| amount | number | 否 | 满减金额（分），type=1 时 |
| discount | number | 否 | 折扣，type=2 时，如 0.9 |
| total | number | 是 | 发放总量 |
| received | number | 是 | 已领取数 |
| per_limit | number | 是 | 每人限领 |
| start_at | number | 是 | 生效时间戳 |
| end_at | number | 是 | 失效时间戳 |
| status | number | 是 | 1启用 0停用 |

索引：`status`、`start_at`、`end_at`

### user_coupon（用户持有券）
| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| coupon_id | string | 是 | 券模板 _id |
| status | number | 是 | 0未使用 1已使用 2已过期 |
| receive_at | number | 是 | 领取时间 |
| use_at | number | 否 | 使用时间 |
| order_id | string | 否 | 使用的订单 _id |

索引：`_openid`、`status`、`coupon_id`

### points_log（积分流水）
| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| change | number | 是 | 变动值，正为获得负为消耗 |
| type | number | 是 | 1消费获得 2抵扣 3退款返还 |
| order_id | string | 否 | 关联订单 _id |
| remark | string | 否 | 备注 |

索引：`_openid`、`created_at`
