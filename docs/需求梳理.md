# 电商微信小程序 · 需求梳理

## 1. 项目定位

| 项 | 说明 |
|----|------|
| 名称 | x-shop（电商微信小程序） |
| 业务模式 | B2C 自营商城（平台自营，单一商家） |
| 目标平台 | 仅微信小程序 |
| 后端方案 | 微信云开发 CloudBase（云函数 + 云数据库 + 云存储） |
| 交付形态 | 可运行的微信小程序 + C 端全链路 |

## 2. 角色

| 角色 | 说明 |
|------|------|
| 消费者（C 端） | 小程序用户，浏览、下单、支付、售后 |
| 运营（B 端后台） | 商品、订单、营销、会员管理（本次为接口能力预留） |
| 系统管理员 | 权限、配置、财务对账（本次为接口能力预留） |

> 本次聚焦 C 端小程序，B 端后台仅做接口能力预留说明。

## 3. 功能需求

### 3.1 商品与购物车
- **分类**：三级树形分类 + 分类 Tab 页
- **商品列表**：按价格/分类/销量筛选、排序、分页加载
- **商品详情**：轮播图、SKU 规格（颜色/尺码等）、库存展示、富文本详情、评价
- **搜索**：关键词搜索、热搜词、历史记录
- **购物车**：加入购物车、数量增减、勾选结算、失效/下架商品标记、合计金额

### 3.2 订单与支付
- **下单**：确认订单页（地址/商品/优惠/运费）、提交下单
- **微信支付**：统一下单 → 拉起支付 → 回调验签
- **订单状态机**：待付款 → 已付款/待发货 → 待收货 → 已完成；含已取消、超时自动关闭
- **售后**：申请退款/退货、退款单流转

### 3.3 物流履约
- **收货地址**：增删改查、默认地址、微信地址导入
- **运费模板**：按区域 + 按件数/重量计价、包邮门槛
- **物流跟踪**：发货后订阅轨迹（第三方物流查询）
- **配送方式**：快递配送 / 到店自提

### 3.4 会员与营销
- **登录**：微信授权登录 + 手机号绑定
- **会员等级**：成长值积累、等级权益（折扣/积分倍率）
- **优惠券**：领券、下单抵扣、使用门槛、过期
- **积分**：消费获得、抵扣、积分流水
- **营销活动**：秒杀、限时折扣（满减/拼团可后置扩展）

## 4. 非功能需求

- **性能**：首页/列表首屏 < 2s，图片懒加载 + CDN + 缩略图
- **安全**：HTTPS、登录态（token）鉴权、支付回调验签、防重放、库存并发控制
- **可用性**：接口幂等、订单超时关闭、弱网容错
- **可扩展**：模块化，营销/物流/支付可插拔

## 5. 里程碑（建议）

| 阶段 | 范围 | 目标 |
|------|------|------|
| MVP | 首页 + 商品（列表/详情/SKU）+ 购物车 + 登录 | 跑通浏览与加购闭环 |
| V1.0 | 订单 + 微信支付 + 收货地址 + 运费 | 跑通交易闭环 |
| V1.5 | 会员等级 + 优惠券 + 积分 | 用户留存与复购 |
| V2.0 | 售后/退款 + 物流跟踪 + 秒杀 | 完整履约与营销 |
